Wahr oder falsch?

Entscheide, ob die Aussage wahr oder falsch ist.

Nr.Aussagewahr oder falsch
1Wer Daten durch einen VPN-Tunnel schickt, schützt sie davor, unterwegs mitgelesen oder manipuliert zu werden.
2Mit einem VLAN wird ein Server im Firmennetz von außen über das Internet erreichbar.
3Die Begriffe Trunk und Cloud meinen dasselbe.
4Auch zwischen genau zwei einzelnen Rechnern lässt sich ein VPN aufbauen.
5Wählt sich eine Mitarbeiterin von zu Hause ins Firmennetz ein, handelt es sich meist um ein Site-to-Site-VPN.

7Pakete mit privaten IP-Adressen werden im Internet weitergeleitet.

9Für ein VLAN muss für jede Abteilung eine eigene Verkabelung verlegt werden.
